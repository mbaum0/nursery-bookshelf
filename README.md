# Nursery Bookshelf

A front-facing book display for the nursery: scalloped tier edges, three open cubbies in the base, and a baseboard cutaway so it sits flush against the wall.

## Open the model

Open `index.html` in a browser. It is a single self-contained file; it loads three.js from a CDN, so it needs an internet connection.

Controls in the model:

- Scallops per tier and scallop depth
- Scalloped or straight back panel
- Books for scale: 0–12 front-facing books in real children's-book sizes, each with its size printed on the cover
- Wood finishes (walnut, cherry, white oak, maple) or paint, including a custom colour picker
- Baseboard trim height and thickness for the rear cutaway
- Camera presets (¾, front, side) and a turntable
- **Build plans**: finished sizes and angles for every part, a grain-aligned rip-strip layout on 4 × 8 ft plywood sheets (matching parts share a strip, fewest rip cuts) with every saw cut numbered in order and each part's final shape, solid-lumber rough sizes and board feet, side dado layout and side profile, to-scale layout-line drawings for the sides and cubby floor, a pocket-hole schedule, fully dimensioned shop drawings of every part (the side as straight edges and true arcs, with an outline point table), and step-by-step assembly renders, all generated from the current settings (print or download as CSV)
